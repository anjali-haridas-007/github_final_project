# Contributor Covenant Code of Conduct

## Our Pledge

We are committed to making participation in this project a welcoming and respectful experience for everyone.

## Expected Behavior

Participants are expected to:
- Be respectful and considerate.
- Communicate constructively.
- Accept feedback politely.
- Focus on what is best for the community.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, and disrespectful behavior are not acceptable.

## Enforcement

Project maintainers may take appropriate action when this code of conduct is violated.
